# 优化记录-20260715

## 1. 处理问题

针对保险合同的问答优化检索方案，将原来的直接检索实体关系再混合打分，调整为以下流程：

1. 根据问题生成过滤查询条件，抽取schema如下：

```json
[
    {
        "field_name": "insurer",
        "field_type": "string",
        "description": "保险产品的发行公司或机构,尽可能使用公司或机构的完整名称",
        "target_index_field": "insurer",
        "match_method": "fuzzy",
        "weight": 1.0,
        "required": true
    },
    {
        "field_name": "contract_name",
        "field_type": "string",
        "description": "保险产品名称，尽可能使用产品完整的名称,例如各种类型保险名称",
        "target_index_field": "contract_name",
        "match_method": "fuzzy",
        "weight": 1.0,
        "required": true
    }
]
```

2. 每个过滤条件召回top-2文档后，使用大模选择最终检索文档

3. 根据问题生查询参数，抽取schema如下：

```json
[
    {
        "field_name": "query_text",
        "field_type": "string",
        "description": "全文搜索内容，对保险合同所有文本进行模糊匹配",
        "target_index_field": "name",
        "match_method": "fuzzy",
        "weight": 1.0,
        "required": true
    },
    {
        "field_name": "entity_name",
        "field_type": "string",
        "description": "保险合同实体名称匹配，如保险人、投保人、被保险人、受益人、保险标的、险种名称、产品名称、贷款，缴费等",
        "target_index_field": "name",
        "match_method": "fuzzy",
        "weight": 0.8,
        "required": false
    },
    {
        "field_name": "subject",
        "field_type": "string",
        "description": "关系主语匹配，指向合同权利与义务的承担主体，如保险人、投保人、被保险人、受益人",
        "target_index_field": "subject",
        "match_method": "fuzzy",
        "weight": 0.4,
        "required": false
    },
    {
        "field_name": "predicate",
        "field_type": "string",
        "description": "关系谓语匹配，描述主体与客体之间的行为或权利义务关系，如承担、缴纳、享有、免除、赔付、通知等",
        "target_index_field": "predicate",
        "match_method": "fuzzy",
        "weight": 0.4,
        "required": false
    },
    {
        "field_name": "object",
        "field_type": "string",
        "description": "关系宾语匹配，代表合同中具体的权利义务客体或要素，如保险责任、保险费、保险金、免赔额、等待期、现金价值等",
        "target_index_field": "object",
        "match_method": "fuzzy",
        "weight": 0.4,
        "required": false
    },
    {
        "field_name": "section_title",
        "field_type": "string",
        "description": "合同章节标题匹配，用于定位特定条款区域，如保险责任、责任免除、投保人如实告知义务、理赔申请、合同解除、借款等标准章节标题",
        "target_index_field": "section_title",
        "match_method": "fuzzy",
        "weight": 0.6,
        "required": false
    }
]
```

4. 沿用原查询流程，但调整加权系数如下：

```json
{
    "entity_channel": 0.25,
    "relation_channel": 0.25,
    "title_channel": 0.3,
    "content_channel": 0.2
}
```

## 2.效果与问题

1. 增加标题的检索，大幅度提高检索命中率
2. 增加步骤1-2，精准限制查询范围
3. 召回文本过滤条件过于粗糙，部分情况消耗token过多，存在异常值
4. 排查错题，答题准确率18/19
